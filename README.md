# 物业维修派单台（离线版）

给物业维修班组用的纯离线派单台：数据只保存在本机浏览器（localStorage），不联网、无后端，刷新不丢。

端口：开发 `5114`，预览 `6114`。

## 使用

```bash
npm install
npm run dev       # 本地开发
npm run build     # 生产构建（输出到 dist/）
npm test          # 自动化测试（node:test，共 40+ 用例）
```

## 功能

- **基础登记**：楼栋、房间（归属楼栋，可记业主/电话）、常用设备、维修人；可设默认工时单价与月度预算。
- **维修单流转**：待派单 → 已接单 → 维修中 → 待验收 → 已验收；待验收可「验收不通过」退回已接单，重新维修后再次提交验收。派单必须指定维修人。
- **列表**：按楼栋、状态、优先级、维修人筛选，按上门时间 / 预算 / 更新时间升降序排列，支持关键词搜索；超过上门时间仍未验收的工单整行标红。
- **工时与耗材**：每张单记录工时、工时单价、耗材数量单价，自动计算材料费、人工费、总费用；实际费用超出单票预算红色提示。
- **顶部统计**：待派单数、逾期数、本月支出（按本月验收完成统计）、未完成预算合计；本月支出超月度预算时顶部告警。
- **防重复提交**：提交验收有领域锁（重复提交报 `DUPLICATE_SUBMIT`），按钮加提交锁防止双击并发。
- **备份与恢复**：
  - 一键导出带校验和的 JSON 备份（文件 / 剪贴板），可从文件或粘贴文本导入（含结构校验，损坏 / 篡改拒绝导入）。
  - 每次保存前自动留存最近 10 份快照，可在「备份与恢复」中手动回退；主数据损坏时自动回退到最近一份完好快照（若都损坏则空库启动并提示）。

## 结构

纯业务逻辑与 UI 分离，逻辑层不依赖 DOM，可直接在 Node 下测试：

```
src/model/   constants / util / calc / workflow / registries / query / backup / store / repo / seed
src/ui/      stats / list / order-form / order-detail / registry / backup / modal / widgets
test/        workflow / calc / query / backup 四组 node:test 用例
```

测试覆盖：派单流转（含退回）、费用计算、筛选排序、备份导出导入与损坏回退、重复提交拦截、统计口径。
